# Recurrent tree indexing: background

Design notes, gap analysis and live results of the OpenSpec change `add-recurrent-tree-indexing`
(`mintmory index-tree`). They moved here from the change folder: the change's `proposal.md`, `specs/` and `tasks.md`
are authoritative, and where these notes differ (for example `design.md` section 4, launchd recurrence, which the
owner left out of scope: indexing runs by hand), the change wins.

- `design.md`: the interface contract as designed.
- `gaps.md`: what MintMory lacked for the task, and the decisions taken.
- `results.md`: the live run on a OneDrive Files-On-Demand tree.
