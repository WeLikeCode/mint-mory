Topology (Postgres HA mode):

  * PodDisruptionBudget: maxUnavailable 1

  DSN Secret: {{ include "mintmory.postgresSecretName" . }}

Topology (SQLite single-writer — fixed, not tunable):

Backups:
{{- if eq $backend "postgres" }}
  Postgres mode: backups are the responsibility of your external database.
  Use your Postgres operator's built-in backup (e.g. CNPG scheduled backups,
  managed-PG snapshots) — no in-cluster chart hook is needed or provided.
  One-time data migration from SQLite:
    mintmory migrate-storage --from sqlite:/path/to/memories.db \
                             --to   postgres://<dsn>
  See the chart README "Runbooks" section for the full procedure.
{{- else }}
  Automated in-cluster backups are NOT shipped as a CronJob: a ReadWriteOnce PVC
  cannot be co-mounted by both the app pod and a CronJob pod. Back up manually:

    kubectl exec --namespace {{ .Release.Namespace }} deploy/{{ include "mintmory.fullname" . }} -- \
      python -c "import sqlite3; s=sqlite3.connect('/data/memories.db'); d=sqlite3.connect('/tmp/backup.db'); s.backup(d); d.close(); s.close()"
    kubectl cp {{ .Release.Namespace }}/<pod>:/tmp/backup.db ./backup.db

  See the chart README for details.
{{- end }}
